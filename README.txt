AVI → MP4 — портативный конвертер для Windows 10/11
====================================================

КАК ЗАПУСТИТЬ
1. Распакуйте ZIP целиком в любую папку (например, на Рабочий стол).
2. Дважды нажмите Convert.bat.
3. Добавьте AVI-файлы кнопкой или перетащите их в список.
4. При необходимости выберите качество и папку для MP4.
5. Нажмите «Конвертировать».

При первом запуске конвертации (если FFmpeg не установлен на компьютере)
программа предложит загрузить видеодвижок FFmpeg с gyan.dev.
Понадобится интернет и примерно 110 МБ для загрузки.
После первой установки FFmpeg остаётся в подпапке bin. Теперь
приложением можно пользоваться полностью офлайн, а всю папку можно
передать другому человеку — повторно скачивать FFmpeg не потребуется.

Что делает программа:
- конвертирует несколько AVI по очереди;
- видео: H.264, звук: AAC, MP4 для удобного воспроизведения;
- показывает прогресс текущего файла;
- предлагает 3 уровня качества и 2 режима скорости;
- не удаляет исходные AVI;
- не перезаписывает MP4: если файл уже есть, добавит (1), (2)...;
- работает с русскими именами файлов и папок.

ПРИМЕЧАНИЯ
- Это полноценное перекодирование, а не простое переименование .avi в .mp4.
- Время обработки зависит от длительности видео, кодека, мощности ПК.
- Большие файлы требуют достаточно места на диске для нового MP4.
- Windows может предупреждать о запуске скачанного BAT-файла или скрипта.
  Запускайте только архив, которому доверяете.
- Если FFmpeg не скачивается, скачайте с https://www.gyan.dev/ffmpeg/builds/
  release essentials и положите ffmpeg.exe и ffprobe.exe в папку bin.
- AVI с очень редкими/повреждёнными кодеками могут не конвертироваться.

ФАЙЛЫ
- Convert.bat         запускает окно конвертера
- AVI-to-MP4.ps1      исходный код интерфейса
- Setup-FFmpeg.ps1    загрузка и проверка FFmpeg
- bin/                здесь будут лежать ffmpeg.exe и ffprobe.exe

FFmpeg не входит в этот ZIP. Он скачивается с сайта сборщика,
на который ссылается официальный сайт FFmpeg.
Подробнее о лицензиях — THIRD_PARTY.txt.
